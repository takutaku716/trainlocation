# 都営交通の列車位置情報

対象は鉄軌道6路線。トップページと走行位置画面の「都営交通」から選択する。

| 路線ID | 路線 | 在線表示 |
| --- | --- | --- |
| 140 | 浅草線 | ODPT実測 |
| 141 | 三田線 | ODPT実測 |
| 142 | 新宿線 | ODPT実測 |
| 143 | 大江戸線 | ODPT実測 |
| 144 | 東京さくらトラム（都電荒川線） | ODPT実測 |
| 145 | 日暮里・舎人ライナー | 未提供の案内と全駅を表示 |

## データ取得

`https://api-public.odpt.org/api/v4/odpt:Train` を、`odpt:operator=odpt.Operator:Toei` と `odpt:railway` で絞り込む。公開APIのためAPIキーやプロキシは不要。2026-09-07にCORSと5路線の実データで動作確認。ローカルサーバーと静的ホスティングの両方で同じ取得処理を利用する。

`js/toei_routes.js` の駅順・駅名・路線方向・列車種別は同APIの `odpt:Railway` / `odpt:TrainType` から作成した2026-09-07時点のマスタ。路線図は `rosen/rosen_140.html` ～ `rosen/rosen_145.html`。マスタを変更する際は対応するHTMLも更新し、下記テストで位置キーを確認する。

日暮里・舎人ライナーは、現時点でODPTの列車位置の提供対象外。時刻表からの推定位置は生成しない。対応開始時は提供仕様を確認し、マスタの `live` を切り替える。現在は同線の位置APIを呼び出さず「位置情報未提供」を表示する。全6路線での実測位置表示には、同線の提供開始または別の位置情報源が必要。

## 変換と表示

- 方向は路線マスタのascending / descendingと照合し、駅順が増える方向を画面下向きとする。
- `fromStation` が在駅位置、`toStation` がある場合は隣接駅間。未知の駅・方向・非隣接区間は推測せず除外し、画面で案内する。
- 大江戸線の都庁前は駅順に2回現れる。駅間は前後の駅で識別。在駅情報だけでは環状部の起終点と通過側を区別できないため、停車中の列車は下段の都庁前（分岐部）に集約する。
- ODPTの遅延は秒単位なので分に変換する。列車番号と種別・行先・提供時刻を表示する。都電の `ODPTnnnn` は配信上の識別番号。
- 都営以外の直通先駅名はアダプター内の辞書で補完する。未登録の行先は「行先取得不可」とする。
- 配信時刻から5分超または `dct:valid` を過ぎた位置は除外。JSONの不正・HTTPエラーを「列車0件」の正常応答として扱わない。更新通信失敗時は旧位置を消して案内する。
- 列車詳細は現在位置・種別・行先・遅延に対応。停車駅時刻表は本実装の対象外。

データ提供：東京都交通局・公共交通オープンデータ協議会。[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。画面に出典と加工表示を掲載している。

## 検証

```powershell
node tools/test_toei_location_adapter.js
node tools/test_toei_location_adapter.js --live
node tools/test_location_background_refresh.js
```

最初のテストは通信不要。全6路線の全駅・両方向・隣接駅間、大江戸線分岐、重複、行先、期限切れ、不正応答、取得失敗を確認する。`--live` は運行時間帯に実行し、取得した全列車に表示先が存在するか確認する。

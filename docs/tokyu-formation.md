# 東急の編成判定表

`original/tokyu_formation.json` は系統ごとに分けて管理する。

- `toyoko_systems`: 東横線系統。東急5000・5050系、横浜高速、相鉄10両、副都心線、東武、西武。
- `meguro_systems`: 目黒線系統。東急3000・3020・5080系、相鉄8両、南北線、都営、埼玉高速。
- `oimachi_systems`: 大井町線。既存の対応を維持。
- `denentoshi`: 既存の予約領域を維持。

各系統内は従来と同じ「両数＋所属」→「2桁の番号」→「編成名」の構成。
表示画面の路線を示す `line_id` より、列車の `train_line_id` を優先する。
26001は東横線、26002は目黒線の表を参照し、別系統の表へのフォールバックは行わない。
新横浜線上でも26001・26002なら同様に判定する。26009の場合は系統未確定として編成名を返さない。

8急38・39は東横線側が5118F・5119F、目黒線側が5188F・5189F。
暫定の8急88・89は削除した。
目黒線系統の運番500〜599・所属「南」・6両は「6埼」の表を使う。
その他の番号・編成名は今回変更していない。
